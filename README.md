# CODE THINK 11

Firebase-only static application. Native Firebase Authentication and Firestore
REST; no Apps Script, Sheets, Cloud Functions or private administrator keys.

Deploy this SITE directory with the root firebase.json. Publish the root rules
and indexes first. Use setup.html once, approve the teacher UID in teacherAccess
through Firebase Console, then upload the private teacher materials from outside SITE.

Start with ../START_HERE_KK.txt or ../README_RU.txt.
Do not open index.html using file://; use HTTPS hosting or START_WINDOWS.cmd.
Only SITE is public. Never upload TEACHER_SETUP or CHECKS as public website files.

1 Мәселе және жобаның мақсаты

Оқушы Python синтаксисін білгенімен, есеп шартынан өз алгоритміне өтуге қиналуы мүмкін. CODE THINK есепті түсіну, жоспарлау, кодты орындап тексеру және қорытынды жасау әрекеттерін бір ортаға біріктіреді. Мақсаты - алгоритмдік ойлауды дамыту. Мұғалім дайын жауаппен бірге жоспарды, кодты және қатені түзету барысын қарай алады.

2 Қолжетімділік пен шектеулер

Заманауи браузер мен интернет керек. Қосымша бағдарлама орнату, рецензенттің жеке аккаунтын беру немесе ақылы жазылым алу талап етілмейді. Python ортасының алғашқы жүктелуі интернет жылдамдығына байланысты уақыт алады. Жүктеу қатесі болса, желіні тексеріп, әрекетті қайталаңыз.

Демода есімдер, бұрынғы жұмыстар, бағалар мен мониторинг сандары - синтетикалық деректер. Өзгерістер тек осы браузер қойындысында сақталады. Жаңа қойынды бөлек демо ашады. Демо Firebase пен Telegram-ға қосылмайды. Нақты аккаунттарды басқару мен пароль өзгерту өшірулі. Негізгі сайтта авторизация мен Firebase қолжетімділігі қажет, оның квоталары бар.

Python орындауы нақты. Қазақша түсіндірме мен визуализация тек қолдау көрсетілетін құрылымдарға арналған оқу көмегі. Барлық Python кітапханасы мен компьютер ресурстары қолжетімді емес. Демо бағалары нақты оқушы жетістігін дәлелдемейді.

3 Негізгі оқу сценарийі

1. Демо сілтемесін ашып, «Апталық шығынды есептеу →» батырмасын басыңыз.

2. «Түсін» және «Жоспарла» бөлімдеріндегі толтырылған үлгілерді қараңыз.

3. «Кодта және тексер» бөліміне өтіп, төмендегі тексеру мысалын орындаңыз.

4. Нәтижені болжаммен салыстырып, себебін жазыңыз. «Салыстыруды сақтау», кейін «Сақтау және қорытындыға өту» батырмаларын басыңыз.

5. «Қорытынды» бөліміндегі екі сұраққа жауап беріңіз. Әр таңдаудан кейін дұрыс жауап пен түсіндірме бірден шығады. Кейін жұмысты мұғалімге тапсырыңыз.

6. Сол қойындының үстіндегі «Мұғалім» сілтемесі арқылы тапсырылған жұмысты қараңыз. Бағалау мен түзетуге қайтару демо деректеріне ғана әсер етеді.

4 Нақты тексеру мысалы

Тапсырма: «Апталық шығынды есептеу». Мақсат - жеті күннің қосындысы мен күндік орташа мәнін есептеу, кейін екі сұрақтық бекітуді тексеру. Негізгі тексеру шамамен 3–5 минут алады, алғашқы Python жүктелуі қосымша уақыт алуы мүмкін.

Бастапқы деректер: 100, 200, 300, 400, 0, 200, 200. Әр сан жеке жолға енгізіледі. Демода код пен осы кіріс алдын ала берілген.

1. «Кодта және тексер» бөлімінде «Кірісті жолдармен енгізу (қосымша)» өрісін ашып, жеті мәнді тексеріңіз.

2. «Орындамай тұрып» болжамына «Жалпы: 1400.00; Орташа: 200.00» деп жазыңыз. «Орындау» батырмасын басыңыз.

3. Нақты нәтижені және визуализациядағы total, average мәндерін салыстырыңыз. Салыстыруға «Болжам сәйкес келді», себебіне «sum(expenses) қосындыны, total / 7 орташа мәнді есептейді» деп жазып, салыстыруды сақтаңыз.

4. «Сақтау және қорытындыға өту» батырмасын басыңыз. Бірінші сұрақта әдейі «100» жауабын таңдаңыз. Дұрыс жауап «700» және түсіндірме шығуы керек. Бұл сұрақтағы кіріс негізгі есеп кірісінен бөлек берілген.

5. Екінші сұрақта «sum(expenses) / len(expenses)» жауабын таңдаңыз. Дұрыстығы расталып, екі сұраққа жауап берілгеннен кейін жұмысты тапсыруға болады.

Қосымша бақылау жұмысты тапсырмас бұрын орындалады: кодтау бөліміне қайта оралып, соңғы кірісті 200-ден 900-ге ауыстырыңыз. Жаңа болжаммен орындағанда «Жалпы: 2100.00» және «Орташа: 300.00» шығады. Мұғалім рөліндегі «Мониторинг» бөлімінен бастапқы және қорытынды диагностиканы салыстыруға болады. Жоқ нәтиже нөлге теңестірілмейді.

5 Авторлық үлес және практикалық пайда

Автор педагогикалық мақсатты, өмірлік есептерді, төрт кезеңді оқу ретін және бағалау сценарийлерін анықтады. Codex HTML, CSS, JavaScript кодын әзірлеуге, функцияларды біріктіруге, қателерді түзетуге және техникалық тексеруге қолданылды. Жобада 31 тапсырма бар: 7 сыныпқа 19, 8 сыныпқа 12. Әр тапсырма соңында екі сұрақтық тест бар. Қате паспорты мен мұғалім мониторингі жеке кері байланысқа көмектеседі. Оқу үлгерімінің өсуі мен уақыт үнемдеу пайызы әзірге өлшенбеген.

Негізгі тәуелділіктер: GitHub Pages, Pyodide, Blockly, SheetJS, ал негізгі нұсқада Firebase. Басқа мектеп тапсырмаларды, сыныптарды және мектеп деректерін бейімдеп қолдана алады. Нақты қолданыста қолжетімділік құқықтары мен сервис квоталары реттеліп, мазмұн мен бағалауды пән мұғалімі тексереді.

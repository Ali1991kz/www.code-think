CODE THINK 11.1.0 — сақтау және оқу нәтижелері

Бұл нұсқа 31 есептің мазмұнын, Python орындаушысын және блок-схема қозғалтқышын сақтайды.

Жаңа мүмкіндіктер:
1. Аккаунтқа бөлек, 14 күндік браузер жобасы. Парольдер жобаға кірмейді.
2. Тапсыруға дайындық тізімі, ескірген болжамды белгілеу және қажетті кезеңге бағыттау.
3. Жалпы /15 балл, әр кезеңнің /3 баллы және мұғалімнің қорытынды пікірі.
4. Сол деңгейдегі сынып ауысқанда бұрынғы есеп жалғасады; өзге деңгейге ауысса оқу тарихы сақталады.
5. Дерекқор соңғы код пен кіріске сәйкес құрылымды болжау/орындау/салыстыру жазбасын тексереді.
6. Дербес бекіту бағасы түсіндіру бағасынан бөлек көрсетіледі.
7. Кабинет бір сұрау тобымен жаңарады; ауыр мұғалім деректері бөлім ашылғанда жүктеледі.
8. Сынып және аты/логин бойынша сүзгі, сынып атауы мен деңгейін тексеру.
9. Excel импорты бір басқанда 50-ден, браузерде сағатына 80 жаңа аккаунттан кейін үзіліспен жүреді.
   Firebase-тің нақты IP шектеуі бөлек қолданылады; басқа құрылғы/ортақ IP әсері болуы мүмкін.
10. Shift+Tab редактордан шығарады, Tab шегініс жасайды.
11. Қорытынды қысқа тесттің балама сұрақтары бар; бұрынғы бағалар қайта есептелмейді.
12. Мұғалімге JSON резерві және бағалар CSV экспорты; резервтен тек жоқ жазбалар қосылады.

Резервтің шегі:
— Тек сол Firebase жобасы мен мұғалімге қалпына келтіріледі.
— Парольдер, Firebase Authentication аккаунттары және жоба баптаулары көшірілмейді.
— Қазіргі жазбалар өшірілмейді немесе алмастырылмайды.
— Аккаунттары бар оқушылардың оқу деректерін қалпына келтіруге арналған.
— Толық жоба апатынан кейін Firebase Authentication-ды қалпына келтіретін әкімшілік резерв емес.

Жариялау:
1. firestore.rules файлын Firebase Console → Firestore → Rules бөліміне жариялау.
2. SITE ішіндегі өзгерген файлдарды GitHub Pages репозиторийінің түбіріне жүктеу.
3. Бетті толық жаңарту. Жаңа CSS және негізгі JavaScript файлдары 11.1.0 белгісімен жүктеледі.
4. Қайта setup жасауға, мұғалімді қайта мақұлдауға, оқушыларды қайта тіркеуге қажет жоқ.

SITE бумасына TEACHER_SETUP, CHECKS, резерв файлдарын, аккаунт деректерін жүктемеңіз.
Биллингті немесе ақылы Firebase қызметтерін қосудың қажеті жоқ.
